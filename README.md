# 2人の記念日サイト (anniversary-site)

〇〇 & △△ の交際記念日を祝うための、二人だけのWebサイトです。
毎年、記念日のたびに新しい思い出を追加しながら育てていく、育成型のサイトです。

## 特徴

- 付き合ってからの日数を自動計算して表示するカウンター
- 年ごとの記念日アイコン(サムネイル+年数バッジ)をタップすると、その年の思い出(タイムライン・写真・手紙)がポップアップで開く
- 新しい年の思い出は、データを1件追加するだけで反映される設計(HTMLを都度書き換える必要なし)

## 使用技術

- HTML / CSS / JavaScript(素の構成、フレームワークなし)
- Git / GitHub でバージョン管理
- GitHub Pages で公開予定

フレームワークを使わずシンプルな構成にしているのは、長く更新し続けるサイトだからこそ、誰が見てもすぐ中身がわかる作りにしたかったためです。

## ローカルでの見方

1. このリポジトリをクローンする
   ```
   git clone <このリポジトリのURL>
   ```
2. `index.html` をブラウザで開く(VSCodeの場合はLive Server拡張機能を使うと便利)

## 今後追加していく思い出の記録方法

`script.js` 内の `anniversaries` という配列に、年ごとのデータをオブジェクトとして追加していきます。詳しい設計方針は `CLAUDE.md` を参照してください。
